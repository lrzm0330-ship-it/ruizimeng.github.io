| 类型            | 能不能改                | 有没有顺序   | 能不能重复     | 核心用途         |
| ------------- | ------------------- | ------- | --------- | ------------ |
| **list列表[ ]** | **✅可以**             | **✅有序** | **✅可以重复** | **存一堆会变的数据** |
| **tuple元组()** | **❌不可以**            | **✅有序** | **✅可以重复** | **表示固定结构**   |
| **set集合{}**   | **✅可以（但元素本身必须不可变）** | **❌无序** | **❌不能重复** | **去重/集合运算**  |
序列类型有==字符串==、==列表==和==元组==，非序列类型有==集合==和==字典==。
序列类型支持双向索引：正向递增索引和反向递减索引。正向递增索引从左向右依次递增，<mark style="background: #FF5582A6;">第一个元素的索引为0</mark>，第二个元素的索引为1，以此类推；反向递减索引从右向左依次递减，从右数<mark style="background: #FF5582A6;">第一个元素的索引为-1</mark>，第二个元素的索引为-2，以此类推
*<font color="#e36c09">0和-1并不是“两种方向”，而是同一条引索轴上的两种标记方式</font>*
其中列表、集合和字典为可变数据类型，创建实例后可修改其中的元素
- s [ 0:2 ] : 从索引0到索引2（不包含2，左闭右开）
- <mark style="background: #FF5582A6;">完整切片结构：[ start : end : step ] : 起点（包含）、终点（不包含）、步长（间隔）</mark>
- s [ 4:0:-2 ] :==步长是负数时，表示从右往左==（s=abcdef则输出‘ ec '）
- 省略写法：s [ : 2] 等价于 s [ 0:2 ]
- s [ ::-1 ] : start省略-默认从末尾开始；end省略-默认到开头结束；-1-从右往左，每次跳一个。输出'fedcba'
- s [ ::-2 ] : 输出' fdb '
- 补充：s[ : -1 ] : 从开头取到倒数第一个元素之前为止（不包含第一个元素）
