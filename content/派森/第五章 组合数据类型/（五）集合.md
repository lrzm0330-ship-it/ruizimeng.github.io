1、集合具备==确定性==、==互异性==和==无序性==三个特性。放入集合中的元素必须是不可变类型，python中的整型、浮点型、字符串类型和元组属于不可变类型，列表、字典及集合本身都属于可变的数据类型
	①确定性：给定一个集合，那么任何一个元素是否在集合中就确定了
	②互异性：集合中的元素互不相同
	③无序性：集合中的元素没有顺序，顺序不同但元素相同的集合可视为同一集合
2、python中的集合本身是可变类型，但python要求放入集合中的元素必须是不可变类型。大括号” { } “ 或内置函数 set() 均可构建集合
- s1={ 1 } #使用大括号构建集合
- s2=set( [ 1,2 ]) #使用set构建元组
3、需要注意，使用 { } 不能创建空集合（不包含元素的 { } 创建的是字典变量），<mark style="background: #FF5582A6;">空集合只能利用set（）函数创建</mark>

4、集合是可变的，集合中的元素可以动态增加或删除。python提供了一些内置方法来操作集合，常见内置方法如下：

| S.add(x)        | 向集合S中添加元素x，x已存在时不做处理                    |
| --------------- | --------------------------------------- |
| **S.remove(x)**     | **删除集合S中的元素x，若x不存在则抛出KeyError异常**           |
| **S.discard(x)**    | **删除集合S中的元素x，若x不存在不做处理**                    |
| **S.pop()**         | **随即返回集合S中的一个元素，同时删除该元素。若S为空，抛出KeyError异常** |
| **S.clear()**       | **清空集合S**                                   |
| **S.copy()**        | **拷贝集合S，返回值为集合**                            |
| **S.isdisjoint(T)** | **判断集合S和T中是否没有相同的元素，没有返回True，有返回False**     |
5、集合也可以利用推导式创建，集合推导式的格式与列表推导式相似，区别在于==集合推导式外侧为大括号“ { } ”==，具体如下：
- { exp for x in set if cond }
