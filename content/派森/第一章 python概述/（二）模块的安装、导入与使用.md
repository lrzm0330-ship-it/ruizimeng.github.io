Python使用import关键字导入模块，其语法格式如下：
<mark style="background: #FF5582A6;">import 模块1，模块2......</mark>
模块导入后，可通过点字符“.”调用模块中的内容，其语法格式如下；
<mark style="background: #FF5582A6;">模块.函数</mark>
<mark style="background: #FF5582A6;">模块.变量</mark>
### 1、from...import
通过点字符调用模块中的内容可避免多个模块中存在同名函数时代码产生歧义，但若不存在同名函数，可使用from...import...语句直接将模块的指定内容导入程序，并在程序中直接使用模块中的内容
- from pygame import init
- init()
*将pygame模块中的init()函数导入程序，并直接使用该函数*
### 2、from...import*
将指定模块的全部内容导入当前程序，* 指代模块中的全部内容，但考虑到代码的可维护性，此种方式不应被过多的使用
- from pygame import*
### 3、pip
###### pip是在终端输入，安装好后在python中通过import调用
利用Python内置的pip工具可以非常方便地安装Python==第三方模块==，该工具可以在命令行中使用，使用该工具在命令行中安装第三方模块的命令为：pip install “模块名”
- pip install pygame
- *安装用于开发游戏的pygame模块*
*pip是在线工具，pip命令执行后，它需要联网获取模块资源，若没有网络或网络不佳，pip将无法顺利安装第三方模块*

### 代码的组织方式——模块、包、库

模块（module）、包（package）和库（lib）是Python组织代码的三种方式
*模块（文件），包（文件夹），库（非常大且功能完整的包）*
