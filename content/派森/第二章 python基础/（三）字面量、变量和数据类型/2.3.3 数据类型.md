### 1、定义
指字面量或者变量的数据等不同存储形式，数据类型分为基础的数字类型和比较复杂的组合类型，其中数字类型又分为==整型、浮点型、布尔类型和复数类型==；组合类型分为==字符串、列表、元组、字典==等

### 2、分类
Python内置的数字类型有整型（int）、浮点型（float）、复数类型（complex）和布尔类型（bool），其中<mark style="background: #FF5582A6;">int、float、complex分别对应数学中的整数、小数和复数</mark>；bool类型比较特殊，是int的子类，只有True和False两种取值

### 3、字符串
一个由单引号、双引号或者三引号包裹的、有序的字符集合
<mark style="background: #ADCCFFA6;">Q、三者区别？</mark>
①单引号和双引号没有本质区别，区分在于输出的要求
![[截屏2026-04-02 19.06.53.png|538]]
②三引号用于处理跨越多行的字符串（避免使用换行符 \n ）
![[截屏2026-04-02 19.08.06.png|500]]
### 4、列表
列表是多个元素的集合，可以保存==任意数量、任意类型==的元素，且可以被修改。python中使用【】创建列表，列表中的元素以逗号分隔
- [1，2，‘hello’]
### 5、元组
元组与列表的作用相似，可以保存==任意数量与类型==的元素，但<mark style="background: #FF5582A6;">不可以被修改</mark>。python中使用（）创建元组，元组中的元素以逗号分隔
- （1，2，‘hello’）

### 6、集合
集合与列表和元组类似，可以保存==任意数量、任意类型==的元素，不同的是，集合使用 { } 创建，集合中的元素<mark style="background: #FF5582A6;">无序且唯一</mark>

### 7、键值对
字典中的元素是“键（key）：值（value）“形式的键值对，键不能重复。python中使用 { } 创建字典，字典中的各元素以逗号分隔
- { "name":"zhangsan","age":18 } （<mark style="background: #FF5582A6;">双引号表示字符串，不加引号表示数字</mark>）
