
range()用来生成一个“整数序列”，共有三种写法
### 1、range(结束值)
格式：range( n )
含义：从 0 开始，到 n-1 结束（不包含n）
### 2、range(开始值，结束值)
格式：range( a, b )
含义：从 a 开始，到 b-1 结束（不包含b）
### 3、range(开始值，结束值，步长)
格式：range( a, b, c )
含义：从 a 开始，每次增加 c ,到 b 前停止

>[!note]
>**Q 、range( 10,0 )表达为什么不对？**
>range()若没有写明，默认步长为1，所以，range( 10, 0 )的含义是“从10开始，每次增加1，到0之前停止”
